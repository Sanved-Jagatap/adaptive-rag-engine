# Contributing to Adaptive RAG Engine

Thank you for your interest in improving Adaptive RAG Engine!

## How to Contribute

### 1. Report a Bug
- Open a GitHub issue describing the problem.
- Include steps to reproduce it, expected behavior, and actual behavior.
- Include relevant error messages, without exposing secrets or personal data.

### 2. Suggest an Improvement
- Describe the proposed improvement and the problem it solves.
- For retrieval or generation changes, explain how the change could be evaluated.

### 3. Submit a Pull Request
1. Fork the repository.
2. Create a focused branch for your change.
3. Install the project dependencies using the project setup instructions.
4. Add or update tests where appropriate.
5. Run the test suite before submitting your changes.
6. Describe the changes and include relevant test results in the pull request.

## Development Guidelines

- Keep changes focused and maintainable.
- Follow the existing project structure and coding conventions.
- Preserve citation validation and insufficient-evidence handling.
- Avoid introducing external API dependencies without discussing the trade-offs.
- Never commit .env files, credentials, local databases, generated logs, or private documents.
- Do not claim performance improvements without supporting evaluation results.

## Questions

For questions or proposed changes, open a GitHub issue with enough context to discuss the problem.
